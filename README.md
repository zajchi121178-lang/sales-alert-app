# Sales Alert App — реализация алерта по сумме покупок за 1 минуту

## Цель задания

Реализовать приложение, которое отправляет алерт, если сумма денег, заработанных по продукту за последнюю минуту, больше 3000.  
Сумма для каждой покупки рассчитывается как: `amount = quantity * price`.

Для генерации данных должны использоваться схемы `purchase.avsc` и `product.avsc` из репозитория `github.com/...s-practice`.

---

## Как должны были использоваться AVSC‑схемы (идеальный пайплайн)

В полном варианте пайплайна:

1. **AVSC‑файлы** (`purchase.avsc`, `product.avsc`) — это Avro‑схемы, которые описывают структуру событий покупки и товаров.
2. **Kafka Connect Datagen** использует эти схемы для генерации реалистичных событий, строго соответствующих описанной структуре.
3. Сгенерированные события отправляются в Kafka‑топик (например, `purchases`).
4. Стриминг‑приложение (Spark Structured Streaming / Kafka Streams) читает из топика, считает `quantity * price`, делает оконную агрегацию за 1 минуту и алертит при превышении порога 3000.

---

## Проблемы при локальной настройке и принятое решение

При попытке развернуть полный стек на Windows возникли проблемы с запуском Kafka‑брокера и Kafka Connect:

- ошибки classpath и отсутствие необходимых утилит (в т.ч. `StorageTool`);
- сложности с настройкой Java‑окружения для корректной работы Kafka Connect Datagen.

Из‑за этого **не удалось запустить генерацию данных через Kafka Connect Datagen**.

Чтобы не терять время на инфраструктурные проблемы и проверить **бизнес‑логику**, было принято решение:

- использовать **моковые данные**, структура которых соответствует полям из AVSC‑схем;
- протестировать на них расчёт `amount = quantity * price`, оконную агрегацию за 1 минуту и проверку порога 3000;
- дополнительно подготовить **PySpark‑код**, который реализует ту же логику в реальном стриминге из Kafka.

Такой подход позволяет продемонстрировать корректность бизнес‑логики и готовность к работе с реальными данными.

## Реализованные скрипты

| Файл | Назначение |
|------|------------|
| `create_topic.py` | Имитирует создание топика `purchases`. Выводит строку, подтверждающую «создание» темы. |
| `producer.py` | Имитирует отправку событий в топик `purchases`. Вместо реального подключения к Kafka выводит сообщения о «отправке» моковых событий. |
| `sales_alert.py` | Реализует логику алерта: считает `amount = quantity * price` для каждого события, агрегирует сумму за «окно в 1 минуту» и выводит алерт, если общая сумма > 3000. |
