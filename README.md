# Sales Alert App

Приложение для алерта: если сумма покупок за 1 минуту больше 3000 — выводится предупреждение.

## Что сделано

- Реализована логика: `amount = quantity * price`.
- Сделана агрегация по окну 1 минута.
- Проверка порога: если сумма > 3000, выводится алерт.
- Так как Kafka Connect Datagen не запустился на Windows, использованы моковые данные (структура соответствует AVSC‑схемам).
- Отдельно подготовлен PySpark‑код для реального стриминга из Kafka.

## Скрипты в репозитории

| Файл | Назначение |
| --- | --- |
| `create_topic.py` | Имитирует создание топика `purchases`. |
| `producer.py` | Имитирует отправку событий в топик. |
| `sales_alert.py` | Считает суммы и выводит алерт при превышении порога. |

## Как запустить (моковая версия)

В терминале в папке проекта выполните:

```bash
python sales_alert.py
